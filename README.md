# 勇吉屋 BASEリニューアル確認用プレビュー

これはBASE本番へ適用する前の確認用プレビューです。

- `index.html`: お客様向け表示を確認するメインプレビュー
- `base-theme-migration-preview.html`: BASE HTML編集 Appへの移設内容を確認する控え
- `contact.html`: お問い合わせページの確認用プレビュー
- `cart.html`: カートページの確認用プレビュー
- `item-detail-preview.html`: 商品詳細ページの確認用プレビュー

商品画像は公開中の商品画像URLを参照しています。
学校名や学校用品を選ぶと、メインプレビュー内の検索結果がリアルタイムに切り替わります。
商品は1ページ最大50件ずつ表示し、ページめくりで確認します。
商品画像または「サイズを選ぶ」を押すと、確認面内の商品詳細が開きます。
商品詳細ではCSVに登録された種類・サイズと数量を選び、確認用カートへ追加できます。
商品詳細はBASE公開商品ページから複数画像と説明文を取り込み、複数画像は前後ボタン・サムネイル・スマホのスワイプで切り替えます。
商品詳細では、購入操作と商品説明の後に、BASEレビュー App原本と同じ「ショップの評価」を表示します。「すべて」と「良い・普通・悪い」の表情アイコン件数で絞り込み、購入商品名・バリエーション・日付・コメント・ショップ返信を原本どおりに扱います。5件ずつのページ切り替えと、新しい順・古い順・評価順・口コミあり優先の並び替えにも対応します。
商品画像は画面幅に応じた候補URLを配信し、タップ・クリックで専用拡大ビューを開きます。商品説明がBASEに未登録の場合は空欄にせず、その旨を表示します。
在庫のない商品は画像から開けず、グレーの「在庫なし」ボタンを表示します。
ヘッダーには `TOP / 店舗について / お問い合わせ / 購入履歴 / カート` の導線を置いています。スマホでは店舗案内を省略し、購入履歴を含む4導線を横一列に収めます。
お問い合わせは新デザイン内で入力と内容確認まで動作し、確認中は実送信を止めています。
カートはプレビュー内で商品追加、数量変更、削除、概算合計まで確認できます。
下部にお支払い方法の案内とgpt-image2生成の説明ビジュアルを掲載しています。
店舗欄には、採寸予約と営業日を公式HPで確認する案内バナーを掲載しています。
スマホは端末の実幅に追従し、320pxを含む各幅でページ全体の横スクロールが出ないようにしています。
日本語は禁則処理とフレーズ単位の自動改行を使い、単語途中の不自然な改行を避けています。
説明画像・商品画像はタップまたはキーボード操作で拡大でき、拡大画面は端末内に余白を残したサイズで表示します。スマホの店舗画像は2枚を小さく並べて表示します。
学校カテゴリページや商品ページなど、BASE本番側へ遷移する確認用リンクは置いていません。
商品表示の補助データは公開商品カードと種類・サイズ・在庫有無に限定し、在庫数、CSV列名、顧客・注文情報は含めません。
商品全件チェックはローカル確認用に限定し、GitHub Pagesには公開しません。
注文、在庫、顧客情報、BASE本番テーマは変更しません。

商品画像・説明文・ショップ評価データの更新と回帰確認:

```sh
node scripts/build-preview-product-details.mjs
node scripts/build-preview-shop-reviews.mjs
node scripts/verify-regression-contract.mjs
```

`../base_redesign/scripts/sync-github-pages-preview.mjs` は旧生成元との差分がある場合に停止する。停止を回避して一括上書きせず、必要な変更を差分レビューして手動統合する。
